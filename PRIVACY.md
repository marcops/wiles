# Wiles Privacy Policy

_Last updated: November 7, 2026_

Wiles is a file manager that works on your Mac. It has no accounts, no ads and no tracking. Your files never leave your Mac unless you share them yourself.

## What Wiles sends

**Error and crash reports.** When Wiles hits an error or crashes, it sends a short report so the problem can be fixed. A report contains:

- what went wrong and where in the app (the error and a stack trace),
- the Wiles version, the macOS version and the type of processor,
- a random identifier created when Wiles is installed, used only to count how many Macs see the same problem.

Before a report is sent, your home folder name is replaced with `/Users/USER` and anything that looks like a password, key or token is removed.

**Feedback.** When you use Send Feedback, the title and description you type are sent the same way.

Reports and feedback are published as issues in the public GitHub repository [marcops/wiles](https://github.com/marcops/wiles/issues), so anyone can read them. Don't include personal information in feedback.

## Purchases

The optional tip in the About window is processed by Apple. Wiles never sees your payment details.

## Contact

Questions about this policy: open an issue at [github.com/marcops/wiles/issues](https://github.com/marcops/wiles/issues).
